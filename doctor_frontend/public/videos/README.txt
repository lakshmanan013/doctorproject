================================================================================
ZENVE ERROR SCREEN ANIMATED VIDEO DIRECTORY
================================================================================

Place your animated video file here!

Default Expected Filename:
  error-animation.mp4
  (or error-animation.webm)

Full Path:
  doctor_frontend/public/videos/error-animation.mp4

How it works:
1. When an internet interruption, server 500/502/503/504 error, or React runtime
   issue occurs, the system automatically runs your animated video on a loop
   instead of showing a blank white page.
2. The video is set to autoplay, loop, muted, and playsInline for maximum browser
   compatibility across all devices.
3. If no video file is placed here yet, a high-tech fallback animation is 
   automatically displayed so the page never looks broken.
4. Once the internet or server is back online, the screen automatically fades out
   and takes the doctor/user right back to the website without manual refreshing!
================================================================================
